# Portfolio Astro

Ce projet est un portfolio construit avec Astro, basé sur le tutoriel officiel Astro en français :
[Astro Tutoriel — Introduction](https://docs.astro.build/fr/tutorial/0-introduction/)

J'ai suivi les étapes de l'unité 1 à l'unité 6 pour créer ce site.

## 📁 Structure du projet

- `public/` : fichiers statiques accessibles directement (images, icônes, etc.)
- `src/pages/` : pages Astro et routes du site
- `src/components/` : composants réutilisables pour l'interface
- `src/layouts/` : mises en page partagées pour les pages et articles
- `src/content.config.ts` : configuration du contenu Markdown / blog
- `package.json` : dépendances et scripts du projet

## 🚀 Commandes utiles

Exécutez ces commandes depuis la racine du projet :

- `npm install` : installe les dépendances
- `npm run dev` : démarre le serveur de développement
- `npm run build` : construit le site pour la production
- `npm run preview` : prévisualise le site construit localement
- `npm run astro -- --help` : affiche l'aide de la CLI Astro

## ℹ️ À propos

Ce site contient :

- une page d'accueil
- une page `about`
- un blog avec des articles Markdown
- des tags et une navigation dynamique
